Cambodia of Wonder School System - Static version
=================================================

What is in this ZIP:
- index.html - the full School Management System (single file, works offline)
- README.txt - this file

How to use:
1. Extract the ZIP.
2. Open index.html in your browser.
   - Khmer / English, with the Cambodia of Wonder School logo.
   - Classes, scores, attendance, tuition, POS, staff, library, ID cards and more.
   - Data is saved in your browser only in this static version.
   - Use Settings > Export / Import JSON in the app to back up your data.

How to put it on GitHub Pages:
1. Create a new GitHub repository, e.g. cambodia-of-wonder-school-system.
2. Upload index.html to the repository (it must be named index.html).
3. Go to Settings > Pages.
4. Under "Branch", select main and folder / (root), then Save.
5. Wait a minute, then open the Pages link GitHub shows you.
